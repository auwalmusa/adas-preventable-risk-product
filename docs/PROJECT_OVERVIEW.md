# Project Overview - ADAS Preventable Risk Detection Product

## Business Problem

Chain-reaction crashes frequently cause preventable secondary impacts (2nd, 3rd, 4th+ collisions).
This product quantifies how many of these secondary impacts could be avoided using existing ADAS technologies (AEB, FCW, ACC).

## Project Goal

Build a complete, senior-level analytical product (not just a script) following the full analytical lifecycle:

- Business requirements
- Data acquisition and automation
- Data governance and quality assurance
- Analysis and risk profiling
- Delivery via interactive dashboard

## Why This Project?

It demonstrates end-to-end ownership of an analytical product, which is the level expected of a Senior Data Analyst in HMRC Risk & Intelligence Service.
